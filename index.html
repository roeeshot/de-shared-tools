DE Shared Tools

DE Shared Tools is an operator-managed application for private Google Drive automation, including encrypted backups and file management. It is intended for the operator's own authorized accounts, rather than general public registration.

Google authorization allows the installed tools to access files within the permissions approved by the account holder. The application may list, read, upload, update or delete authorized files as required by the operator's workflows. Backup files and account credentials are not published on this website.

This website provides application information only. It does not offer a sign-in form or request Google passwords or authorization tokens.
